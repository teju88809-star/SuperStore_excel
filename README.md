# SuperStore_excel
Excel Data Analysis – Sample Superstore Dataset

📌 Description

This project focuses on analyzing retail sales data using Microsoft Excel. The objective is to understand sales performance, profitability, customer segments, and regional trends through Excel formulas and summary tables.

🎯 Objective

To analyze a structured dataset, calculate key performance indicators (KPIs), and extract meaningful business insights to support data-driven decision-making.

🛠️ Tools Used

- Microsoft Excel
- Excel formulas
- Sorting and filtering
- Summary tables and PivotTable-style analysis

📂 Project Deliverables

- Raw dataset
- Working formulas and KPI calculations
- Sales analysis by category
- Sales analysis by region
- Customer segment analysis
- Discount and subcategory analysis
- Summary of key findings

📊 Key Analysis Areas

- Total sales and total profit
- Profit margin
- Category-wise sales performance
- Region-wise sales performance
- Customer segment performance
- Discount and profitability analysis

💡 Key Learnings

- Improved Excel data analysis skills.
- Learned to calculate and interpret KPIs.
- Understood how to compare sales and profitability across business categories.
- Practiced organizing data and presenting business insights.

⚠️ Dataset Limitation

The supplied dataset does not contain an Order Date column. Therefore, monthly or seasonal sales trends cannot be analyzed using this version of the dataset.

🚀 Conclusion

This task provided practical experience in using Excel to analyze retail data and identify insights that can support business decisions.
